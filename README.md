# Music Search Bot

ربات جستجوی هوشمند موسیقی برای تلگرام 🎵

## قابلیت‌ها

- 🎵 جستجوی آهنگ با نام آهنگ
- 🎤 جستجو با نام خواننده
- 📝 جستجو با بخشی از متن آهنگ
- 🎧 دریافت فایل صوتی
- 🎬 دریافت ویدئو و استخراج آهنگ
- 🔎 تشخیص هوشمند نوع درخواست

## وضعیت پروژه

نسخه اولیه پروژه در حال توسعه است.

## امنیت

توکن ربات تلگرام نباید داخل GitHub قرار بگیرد.

توکن در مرحله اتصال به سرور به صورت Environment Variable با نام زیر تنظیم می‌شود:

BOT_TOKEN
